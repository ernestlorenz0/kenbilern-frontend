# Kenbilern Frontend

Interactive slideshow editor with AI-powered image generation.

## Features
- Drag and drop slide editor
- AI image generation (Gemini API)
- Firebase authentication
- Responsive UI with Tailwind

## Tech Stack
React, Vite, Konva.js, Tailwind CSS, Firebase

## Setup
git clone https://github.com/yourusername/kenbilern.git
cd kenbilern-frontend
npm install
npm run dev

## Architecture
Frontend (React)
   ↓ REST API
Backend (Flask)
   ↓
Firebase + Gemini API
